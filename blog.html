Introduction to Python

When I first started learning Python, I didn’t really know anything about programming at all. I decided to learn it independently because I needed it for robotics, and I was intrigued by the code for our robot. One of the first concepts I learned was variables. I learned that variables help you store information so that you can use it in your program. As an example, I used: name = “Joey” age = 14 print(name) print(age) This made 2 variables and printed their values. Another concept I learned was if statements. They allow a program to make decisions based on whether something is true or false. I used this code: age = 14 if age >= 13: print(“You are a teenager!”) else: print(“You are not a teenager yet!”) This checks whether the age is at least 13. The third concept I learned was loops, which are useful if you want to repeat something. For example: for i in range(500): print(“Learning Python”) This prints “Learning Python” 500 times. Instead of writing the same print() statement 500 times, I can use loop to repeat it. One problem I ran into was forgetting that Python uses indentation. Without indentation, the code would not run. So far, Python has shown me that coding is a lot of trial and error, and you just need to get the hang of it and learn to learn from your mistakes. Hopefully, in the future I can learn how to build big projects and use Python for robotics too!
